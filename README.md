
# Yandex HakaTon

Проект **Yandex HakaTon** был разработан в рамках хакатона, организованного Яндексом для лучших учеников [Яндекс Лицея](https://yandexlyceum.ru/). Хакатон проходил в главном офисе Яндекса и стал отличной возможностью продемонстрировать навыки программирования, работы в команде и проектирования решений.

## О проекте

Данный проект представляет собой веб-приложение, реализованное на Flask, с использованием базы данных SQLite. Основной функционал включает регистрацию пользователей, авторизацию, добавление и управление задачами, а также публикацию и удаление объявлений. 

### Основные функции
1. **Регистрация и авторизация:**
   - Регистрация новых пользователей с валидацией данных.
   - Авторизация пользователей с использованием сессий.
   - Функционал для администраторов (выделенные права).

2. **Работа с задачами:**
   - Добавление новых задач.
   - Удаление задач.
   - Просмотр списка задач с их статусами.

3. **Управление объявлениями:**
   - Создание новых объявлений.
   - Удаление объявлений (только администраторами).

4. **Роли пользователей:**
   - Администраторы (заданы в файле `admins.txt`).
   - Обычные пользователи.

5. **Валидация форм:**
   - Используются Flask-WTF и WTForms для удобной работы с формами.

### Используемые технологии
- **Язык программирования:** Python
- **Веб-фреймворк:** Flask
- **База данных:** SQLite
- **Фронтенд:** HTML-шаблоны с использованием Jinja2

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/GameTrue/Yandex_HakaTon.git
   ```
2. Убедитесь, что у вас установлен Python 3.7 или выше.
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Инициализируйте базу данных:
   - Убедитесь, что файл базы данных `data.db` существует в корневой папке проекта.
   - Если файл отсутствует, он создастся автоматически при первом запуске приложения.
5. Запустите сервер:
   ```bash
   python ax/server.py
   ```
6. Откройте в браузере:
   ```
   http://127.0.0.1:8080/
   ```

## Структура проекта

- `ax/server.py`: Основной серверный скрипт, где описана логика приложения.
- `ax/loginform.py`: Форма авторизации.
- `ax/registerform.py`: Форма регистрации.
- `ax/SolverForm.py`: Форма для добавления задач.
- `ax/data.db`: SQLite база данных для хранения пользователей, задач и объявлений.
- `ax/static/admins.txt`: Файл с данными об администраторах.
- `templates/`: HTML-шаблоны для рендеринга страниц.
